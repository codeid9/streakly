# Habit Grow

Habit Grow is a modern habit tracking application that helps users build better habits, maintain streaks, and track their daily progress.

## Features

- Create, edit, and delete habits
- Daily habit tracking
- Streak tracking system
- Progress statistics
- Calendar view
- Light and dark mode
- Responsive design
- Smooth animations
- LocalStorage data persistence

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite

## Installation

```bash
git clone https://github.com/your-username/habit-grow.git

cd habit-grow

npm install

npm run dev
